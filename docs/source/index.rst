News Outside – Documentation
============================

News Outside is a Django-based news publishing platform with role-based access
control for three user roles: **Journalists**, **Editors**, and **Readers**.

Features
--------

* Role-based access control (journalist, editor, reader)
* Article creation, editing, and deletion per role
* Editor approval workflow for articles
* Newsletter creation, editing, and deletion per role
* Publisher management and reader subscriptions
* RESTful API (Django REST Framework)
* Email notifications via signals
